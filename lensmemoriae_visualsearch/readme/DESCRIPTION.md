Visual search for your LensMemoriae archive. Search for visually similar photographs
by example: paste an image (Ctrl+V) or attach a file, and the module finds the closest
matches using perceptual hashing (`imagehash`).

Main features:

- Paste from the clipboard or attach a file to search by example
- Finds the source image even when only a part (crop) of it is pasted
- Region-based perceptual-hash index (whole image, tiles and overlapping windows)
- Visual Index management screen to monitor and (re)build the hash index
- Manual indexing per image and hashes shown in the image detail view
- Search filters by index state in the Images screen

To search by example:

1.  Go to _LensMemoriae \> Visual Search_.
2.  Paste an image (Ctrl+V), drag &amp; drop one, or click to attach a file.
3.  Optionally adjust the similarity threshold (Very close / Similar / Flexible) and
    the maximum number of results.
4.  Click **Search**. The closest matches are shown as a grid with a similarity
    percentage. The red box on a thumbnail highlights the region of the original photo
    that matches the pasted part. Click a result to open the image record.

To manage the hash index (moderators):

-   _LensMemoriae \> Visual Index_ shows a summary (images with data, indexed, pending
    and errors), a progress bar, and lists images per state. Use **Index pending** to
    build hashes for images still pending and **Reindex all** to rebuild everything.
-   From an image form, moderators can use the **Index Image** button to compute the
    hashes for that single image, and review the computed hashes in the
    _Visual Search Index_ group (state, date, count and the list of hashes per region).
-   The _Images_ screen offers _Visual Indexed_ / _Visual Pending_ / _Visual Index Error_
    filters.

Description
===========

This module allows Odoo to scan a filesystem directory, index images, and
provide a rich interface to browse, tag, moderate, and share them.

Features:

- Automatic filesystem scanning
- Tagging and filtering
- Image moderation with approval workflow
- Geolocation with interactive Leaflet map
- Word cloud from approved notes
- Public gallery and self-registration
- Bulk tagging operations

Configuration
=============

Go to *LensMemoriae > Configuration > Settings* and set the base path to your
images directory.

Assign the *Moderator* group to users who should approve or reject image notes.

Usage
=====

#. Go to *LensMemoriae > Images* to browse all scanned images.
#. Click an image to view details, add tags, or leave notes.
#. Use the *Map* view to explore geolocated images.
#. Moderators can approve or reject notes from the *Moderation Queue*.
#. Use *Configuration > Stop Words* to manage the word cloud.

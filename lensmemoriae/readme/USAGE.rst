To use LensMemoriae:

1. Go to *LensMemoriae > Images* to browse all scanned images.
2. Click an image to view details, add tags, or leave notes.
3. Use the *Map* view to explore geolocated images.
4. Moderators can approve or reject notes from the *Moderation Queue*.
5. Use *Configuration > Stop Words* to manage the word cloud.

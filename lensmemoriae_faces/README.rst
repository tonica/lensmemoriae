Description
===========

Automatically detects faces in images and groups them by person.

- Automatic face detection on image scan
- Person grouping and naming
- Batch face identification wizard

Configuration
=============

No additional configuration required. This module depends on LensMemoriae
and works with its existing image scanning setup.

Usage
=====

After installation, faces are detected automatically when images are scanned.

Go to *LensMemoriae > Faces* to review detected faces, assign them to known
persons, or use the *Batch Identify* wizard to process multiple faces at once.
